# MyProject · Lumen workspace

This folder is a UI / source-editing demo, not a complete Unity project.
The C# files are sample components; Unity itself is not bundled or connected.

## Run a real task
Open Examples/hello.py, hello.js, hello.c, hello.cpp or hello.S and press F5.
Trust the workspace only if you recognize its source files. Programs run with your user permissions.
Python uses Lumen's Python interpreter. C/C++ need gcc/g++, JavaScript needs Node.js.
The .S example needs Linux x86-64 (including compatible WSL).

## Editing
Ctrl+S saves to disk. Ctrl+P searches files. Ctrl+Shift+P opens commands.
A concurrent external change is detected before overwrite. Backups live in .lumen/backups.

## UI
The sun/moon/leaf button selects Day, Midnight or Forest without changing layout.
The lower-left landscape opens appearance settings.
